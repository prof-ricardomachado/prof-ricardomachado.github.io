O coeficiente \(2\) em \(y\) nos impede de usar a fórmula diretamente, mas podemos dividir o problema em casos baseando-nos nos valores possíveis para \(y\text{.}\) Como \(y \geq 0\) e \(2y \leq 8\text{,}\) \(y\) só pode assumir valores de 0 a 4.
  • Se \(y = 0\text{:}\) \(x + z = 8 \implies CR_2^8 = 9\) soluções.
  • Se \(y = 1\text{:}\) \(x + z = 6 \implies CR_2^6 = 7\) soluções.
  • Se \(y = 2\text{:}\) \(x + z = 4 \implies CR_2^4 = 5\) soluções.
  • Se \(y = 3\text{:}\) \(x + z = 2 \implies CR_2^2 = 3\) soluções.
  • Se \(y = 4\text{:}\) \(x + z = 0 \implies CR_2^0 = 1\) solução.
Pelo Princípio Aditivo, somamos os casos:
\begin{equation*} 9 + 7 + 5 + 3 + 1 = 25. \end{equation*}
