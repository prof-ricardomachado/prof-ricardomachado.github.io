Fazemos a mudança de variáveis para garantir os múltiplos: \(x_1 = 3a\text{,}\) \(x_2 = 3b\text{,}\) \(x_3 = 3c\text{,}\) \(x_4 = 3d\text{,}\) com \(a, b, c, d \geq 0\text{.}\)
Substituindo na equação:
\begin{equation*} 3a + 3b + 3c + 3d = 18 \implies a + b + c + d = 6. \end{equation*}
Calculamos as combinações completas:
\begin{equation*} CR_4^6 = PR_9^{6, 3} = 84. \end{equation*}
