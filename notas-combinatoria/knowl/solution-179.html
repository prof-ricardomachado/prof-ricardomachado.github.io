Solução 2.3.3.5.1.

Temos 3 grupos de 2 elementos idênticos. O tabuleiro de posições proibidas é formado por três blocos disjuntos de \(2 \times 2\text{.}\) O polinômio de torre de um único bloco \(2 \times 2\) é \(2x^2 + 4x + 1\text{.}\)
O polinômio de torre total é:
\begin{align*} R(x, T) \amp = (2x^2 + 4x + 1)^3 \\ \amp = 8x^6 + 48x^5 + 108x^4 + 116x^3 + 66x^2 + 12x + 1 \end{align*}
Substituindo \(x^k\) por \((-1)^k (6-k)!\text{,}\) o número de maneiras de realocar os carros, se fossem todos distintos, seria:
\begin{align*} N_{\text{dist}} \amp = 720 - 12(120) + 66(24) - 116(6) + 108(2) - 48(1) + 8(1) \\ \amp = 720 - 1440 + 1584 - 696 + 216 - 48 + 8 = 344 \end{align*}
Como os carros da mesma cor são idênticos, devemos dividir o resultado pelo fatorial das repetições de cada cor:
\begin{equation*} DR_6^{2,2,2} = \frac{344}{2! \times 2! \times 2!} = \frac{344}{8} = 43 \text{ maneiras}. \end{equation*}
