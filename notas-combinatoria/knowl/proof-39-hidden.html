Faremos a demonstração por indução matemática sobre \(n\text{.}\)
Casos base:
  • Para \(n=0\text{:}\) a soma tem apenas o termo \(k=0\text{,}\) logo \(S_0 = C_0^0 = 1 = F_1\text{.}\)
  • Para \(n=1\text{:}\) a soma também possui apenas \(k=0\text{,}\) logo \(S_1 = C_1^0 = 1 = F_2\text{.}\)
A relação é, portanto, válida para \(n=0\) e \(n=1\text{.}\)
Passo indutivo: Fixado \(n \ge 1\text{,}\) assumimos como hipótese de indução que a fórmula seja válida para todos os inteiros não negativos menores ou iguais a \(n\) (em particular, para \(S_n = F_{n+1}\) e \(S_{n-1} = F_n\)). Queremos mostrar que ela é válida para \(n+1\text{,}\) isto é, que \(S_{n+1} = F_{n+2}\text{.}\)
Pela definição da soma para o índice \(n+1\text{:}\)
\begin{equation*} S_{n+1} = \sum_{k=0}^{\lfloor \frac{n+1}{2} \rfloor} C_{n+1-k}^k. \end{equation*}
Separando o termo \(k=0\) e aplicando a Relação de Stifel (\(C_{n+1-k}^k = C_{n-k}^k + C_{n-k}^{k-1}\)) nas parcelas com \(k \ge 1\text{,}\) obtemos:
\begin{align*} S_{n+1} \amp = C_{n+1}^0 + \sum_{k=1}^{\lfloor \frac{n+1}{2} \rfloor} \left( C_{n-k}^k + C_{n-k}^{k-1} \right) \\ \amp = C_{n+1}^0 + \sum_{k=1}^{\lfloor \frac{n+1}{2} \rfloor} C_{n-k}^k + \sum_{k=1}^{\lfloor \frac{n+1}{2} \rfloor} C_{n-k}^{k-1}. \end{align*}
Como \(C_{n+1}^0 = C_n^0 = 1\text{,}\) incorporamos esse termo inicial ao primeiro somatório:
\begin{equation*} S_{n+1} = \sum_{k=0}^{\lfloor \frac{n+1}{2} \rfloor} C_{n-k}^k + \sum_{k=1}^{\lfloor \frac{n+1}{2} \rfloor} C_{n-k}^{k-1}. \end{equation*}
Analisamos agora individualmente cada um dos dois somatórios:
1. Primeiro somatório: Examinamos o limite superior \(\lfloor \frac{n+1}{2} \rfloor\) de acordo com a paridade de \(n\text{:}\)
  • Se \(n\) for par (\(n = 2m\)): temos \(\lfloor \frac{n+1}{2} \rfloor = \lfloor \frac{2m+1}{2} \rfloor = m\) e \(\lfloor \frac{n}{2} \rfloor = m\text{.}\) Logo, os limites superiores coincidem.
  • Se \(n\) for ímpar (\(n = 2m+1\)): temos \(\lfloor \frac{n+1}{2} \rfloor = m+1\text{,}\) ao passo que \(\lfloor \frac{n}{2} \rfloor = m\text{.}\) Para o termo extra correspondente a \(k = m+1\text{,}\) o coeficiente binomial resultante é:
    \begin{equation*} C_{n-k}^k = C_{(2m+1)-(m+1)}^{m+1} = C_m^{m+1} = 0, \end{equation*}
    uma vez que o numerador é estritamente menor que o denominador.
Portanto, em ambos os casos, a parcela com \(k = \lfloor \frac{n+1}{2} \rfloor\) é nula ou já está contida em \(\lfloor \frac{n}{2} \rfloor\text{,}\) o que nos permite reescrever o primeiro somatório exatamente como \(S_n\text{:}\)
\begin{equation*} \sum_{k=0}^{\lfloor \frac{n+1}{2} \rfloor} C_{n-k}^k = \sum_{k=0}^{\lfloor \frac{n}{2} \rfloor} C_{n-k}^k = S_n. \end{equation*}
2. Segundo somatório: Efetuamos a mudança de variável \(j = k - 1\) (de modo que \(k = j + 1\)). Quando \(k = 1\text{,}\) temos \(j = 0\text{.}\) Para o limite superior:
\begin{equation*} j_{\text{máx}} = \left\lfloor \frac{n+1}{2} \right\rfloor - 1 = \left\lfloor \frac{n+1 - 2}{2} \right\rfloor = \left\lfloor \frac{n-1}{2} \right\rfloor. \end{equation*}
Substituindo \(k = j+1\) no coeficiente binomial:
\begin{equation*} C_{n-k}^{k-1} = C_{n-(j+1)}^j = C_{(n-1)-j}^j. \end{equation*}
Logo, esse somatório torna-se:
\begin{equation*} \sum_{k=1}^{\lfloor \frac{n+1}{2} \rfloor} C_{n-k}^{k-1} = \sum_{j=0}^{\lfloor \frac{n-1}{2} \rfloor} C_{(n-1)-j}^j = S_{n-1}. \end{equation*}
Reunindo os dois resultados e aplicando a hipótese de indução:
\begin{equation*} S_{n+1} = S_n + S_{n-1} = F_{n+1} + F_n. \end{equation*}
Pela relação de recorrência fundamental da sequência de Fibonacci (\(F_{n+2} = F_{n+1} + F_n\)), concluímos que:
\begin{equation*} S_{n+1} = F_{n+2}, \end{equation*}
o que completa o passo indutivo e encerra a demonstração.
