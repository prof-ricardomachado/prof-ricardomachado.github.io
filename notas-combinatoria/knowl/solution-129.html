Solução 1.7.12.1.

Como as bolas de cores diferentes são independentes, podemos calcular a distribuição das bolas brancas, depois a das pretas, e multiplicar os resultados (Princípio Multiplicativo).
Para as 7 bolas brancas nas 4 caixas, resolvemos \(b_1 + b_2 + b_3 + b_4 = 7\text{.}\) O número de soluções é:
\begin{equation*} CR_4^7 = PR_{10}^{7, 3} = 120. \end{equation*}
Para as 5 bolas pretas nas 4 caixas, resolvemos \(p_1 + p_2 + p_3 + p_4 = 5\text{.}\) O número de soluções é:
\begin{equation*} CR_4^5 = PR_8^{5, 3} = 56. \end{equation*}
Multiplicando as possibilidades, obtemos a resposta final:
\begin{equation*} 120 \times 56 = 6720. \end{equation*}
