Primeiro, fazemos a mudança de variáveis para remover as restrições inferiores: \(x = a+1\text{,}\) \(y = b+2\) e \(z = c+3\text{,}\) com \(a, b, c \geq 0\text{.}\)
Substituindo na inequação:
\begin{equation*} (a+1) + (b+2) + (c+3) \leq 12 \implies a + b + c \leq 6. \end{equation*}
Para transformar a inequação em equação, introduzimos uma variável de folga \(f \geq 0\text{:}\)
\begin{equation*} a + b + c + f = 6. \end{equation*}
O número de soluções é:
\begin{equation*} CR_4^6 = PR_9^{6, 3} = 84. \end{equation*}
