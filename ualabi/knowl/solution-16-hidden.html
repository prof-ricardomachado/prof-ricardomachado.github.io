1. Análise de Graus de Entrada (Teoria dos Grafos):
O tabuleiro pode ser modelado como um digrafo orientado onde cada casa possui exatamente 1 aresta de saída (o sentido da seta). Para existir um Caminho Hamiltoniano (que visita todos os 12 vértices exatamente uma vez sem repetir):
  • Todo vértice visitado após o início precisa ter grau de entrada pelo menos 1 (deve haver uma seta apontando para ele).
  • Se um vértice tiver grau de entrada 0 (nenhuma seta apontando para ele), é impossível chegar a ele vindo de qualquer outra casa.
Examinando o tabuleiro, a casa A1 tem seta apontando para B1, mas nenhuma outra casa aponta para A1. Logo, se o percurso começasse em qualquer outra casa, A1 jamais seria visitada. Portanto, o percurso deve obrigatoriamente começar em A1.
