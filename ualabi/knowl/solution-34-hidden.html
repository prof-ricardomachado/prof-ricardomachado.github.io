Resolução Detalhada:
O problema baseia-se no conceito de Invariante de Paridade:
  1. Seja \(C\) a quantidade de cartões com a face cinza voltada para cima. No início, \(C = 0\) (par).
    • Virar dois cartões brancos: ambos viram cinzas, logo \(\Delta C = +2\text{;}\)
    • Virar um branco e um cinza: o branco vira cinza e o cinza vira branco, logo \(\Delta C = +1 - 1 = 0\text{;}\)
    • Virar dois cartões cinzas: ambos voltam a ser brancos, logo \(\Delta C = -2\text{.}\)
  3. Em todas as possibilidades, a variação \(\Delta C\) é um número par. Logo, a paridade de \(C\) é invariante:
    \begin{equation*} C \equiv 0 \pmod 2 \quad (\text{a quantidade de cartões cinzas é obrigatoriamente PAR}). \end{equation*}
  4. Para que todos os cartões fiquem cinzas, precisaríamos de \(C = 5\text{.}\) Como \(5\) é ímpar e o invariante exige que \(C\) seja par, é impossível atingir esse objetivo.
