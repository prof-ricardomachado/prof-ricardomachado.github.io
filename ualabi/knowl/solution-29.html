Solução 3.1.45.1.

1. Modelagem em Álgebra Booleana / Espaço Vetorial \(\mathbb{F}_2^4\text{:}\)
Associamos Círculo a \(0\) e Triângulo a \(1\text{.}\) O estado inicial é o vetor:
\begin{equation*} v_0 = (1, 0, 1, 0)^T. \end{equation*}
Queremos alcançar o vetor nulo \(v_f = (0, 0, 0, 0)^T\) aplicando combinações lineares dos vetores de transição de cada botão:
  • Apertar Botão 1: alterna posições 1 e 2 $\implies e_1 = (1, 1, 0, 0)^T$.
  • Apertar Botão 2: alterna posições 1, 2 e 3 $\implies e_2 = (1, 1, 1, 0)^T$.
  • Apertar Botão 3: alterna posições 2, 3 e 4 $\implies e_3 = (0, 1, 1, 1)^T$.
  • Apertar Botão 4: alterna posições 3 e 4 $\implies e_4 = (0, 0, 1, 1)^T$.
2. Busca do Mínimo de Movimentos:
Como a operação é comutativa e \(x \oplus x = 0\text{,}\) cada botão é apertado no máximo 1 vez.
Avaliando o sistema linear sobre \(\mathbb{F}_2\text{,}\) exatamente 2 toques são necessários e suficientes para neutralizar as alternâncias e transformar todos os botões em círculos.
