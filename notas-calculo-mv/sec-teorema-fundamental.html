    Seção 2.3 O Teorema Fundamental para Integrais de Linha

    Inicialmente, lembre que um campo vetorial \(\vec{F}: \mathbb{R}^n \rightarrow \mathbb{R}^n\) é dito conservativo quando existe um campo escalar \(\varphi: \mathbb{R}^n \rightarrow \mathbb{R}\) tal que \(\nabla\varphi = \vec{F}\text{.}\)

    Teorema 2.3.1. Teorema Fundamental das Integrais de Linha.

    Se \(\vec{F}: D \subseteq \mathbb{R}^n \rightarrow \mathbb{R}^n\) é um campo vetorial contínuo, se \(\varphi: D \subseteq \mathbb{R}^n \rightarrow \mathbb{R}\) é tal que \(\nabla\varphi = \vec{F}\) e se \(\gamma: [a,b] \rightarrow \mathbb{R}^n\) é uma curva de classe \(C^1\) com \(\gamma(a) = A\) e \(\gamma(b) = B\text{,}\) então:
    \begin{equation*} \int_{\gamma} \vec{F} \cdot d\vec{r} = \int_{\gamma} \nabla\varphi \cdot d\vec{r} = \varphi(B) - \varphi(A) \end{equation*}

    Demonstração.

    Temos que \(\int_{\gamma} \vec{F} \cdot d\vec{r} = \int_{a}^{b} \vec{F}(\gamma(t)) \cdot \gamma'(t) \, dt\text{.}\)
    Como \(\vec{F} = \nabla\varphi\text{,}\) segue que:
    \begin{equation*} \vec{F}(\gamma(t)) = \left( \frac{\partial\varphi}{\partial x_1}(\gamma(t)), \frac{\partial\varphi}{\partial x_2}(\gamma(t)), \dots, \frac{\partial\varphi}{\partial x_n}(\gamma(t)) \right) \end{equation*}
    Daí, efetuando o produto interno:
    \begin{align*} \vec{F}(\gamma(t)) \cdot \gamma'(t) \amp = \frac{\partial\varphi}{\partial x_1}(\gamma(t))\frac{dx_1(t)}{dt} + \dots + \frac{\partial\varphi}{\partial x_n}(\gamma(t))\frac{dx_n(t)}{dt}\\ \amp = \frac{d}{dt}\big(\varphi(\gamma(t))\big) \quad \text{(pela Regra da Cadeia)} \end{align*}
    Logo:
    \begin{equation*} \int_{\gamma} \vec{F} \cdot d\vec{r} = \int_{a}^{b} \frac{d}{dt}\big(\varphi(\gamma(t))\big) \, dt = \varphi(\gamma(b)) - \varphi(\gamma(a)) = \varphi(B) - \varphi(A) \end{equation*}

    Nota 2.3.2.

    O teorema acima nos diz que a integral de linha de um campo conservativo sobre uma curva suave \(\gamma: [a,b] \rightarrow \mathbb{R}^n\) depende apenas dos pontos extremos do intervalo, ou seja, de \(\gamma(a)\) e \(\gamma(b)\text{.}\)

    Exemplo 2.3.3.

    Calcule \(\int_{\gamma} x \, dx + y \, dy\text{,}\) onde \(\gamma(t) = (\arctan t, \text{sen}(t^3))\text{,}\) \(0 \le t \le 1\text{.}\)
    Solução.
    Note que se calcularmos diretamente pela definição, faríamos:
    \begin{align*} x = \arctan t \amp \implies dx = \frac{1}{1+t^2} \, dt\\ y = \text{sen}(t^3) \amp \implies dy = 3t^2 \cos(t^3) \, dt \end{align*}
    Obtendo \(\int_{0}^{1} \left( \frac{\arctan t}{1+t^2} + 3t^2 \text{sen}(t^3)\cos(t^3) \right) dt\text{.}\) Embora essas integrais não sejam impossíveis, elas exigem bastante trabalho algebraico.
    Por outro lado, note que \(\varphi(x,y) = \frac{x^2+y^2}{2}\) é tal que \(\frac{\partial\varphi}{\partial x} = x\) e \(\frac{\partial\varphi}{\partial y} = y\text{,}\) isto é, \(\varphi\) é uma função potencial para o campo \(\vec{F} = x\vec{i} + y\vec{j}\text{.}\)
    Assim, usando o Teorema Fundamental das Integrais de Linha:
    \begin{align*} \int_{\gamma} x \, dx + y \, dy \amp = \varphi(\gamma(1)) - \varphi(\gamma(0))\\ \amp = \varphi(\arctan 1, \text{sen } 1) - \varphi(\arctan 0, \text{sen } 0)\\ \amp = \varphi\left(\frac{\pi}{4}, \text{sen } 1\right) - \varphi(0,0)\\ \amp = \frac{(\pi/4)^2 + \text{sen}^2 1}{2} - \frac{0^2+0^2}{2} = \frac{1}{2}\left(\frac{\pi^2}{16} + \text{sen}^2 1\right) \end{align*}

    Subseção 2.3.1 Independência do Caminho e Curvas Fechadas

    Definição 2.3.4.

    Diremos que a integral de linha \(\int_C \vec{F} \cdot d\vec{r}\) é independente do caminho quando \(\int_{C_1} \vec{F} \cdot d\vec{r} = \int_{C_2} \vec{F} \cdot d\vec{r}\) para quaisquer dois caminhos \(C_1\) e \(C_2\) que tenham os mesmos pontos inicial e final.
    Nesta terminologia, pelo Teorema Fundamental, para calcular a integral de um campo conservativo precisamos apenas dos pontos extremos da curva. Logo, concluímos que a integral de linha de um campo conservativo é independente do caminho.

    Exemplo 2.3.5.

    Considere o campo conservativo \(\vec{F}(x,y) = (e^{-y} - 2x)\vec{i} + (-x e^{-y} - \text{sen } y)\vec{j}\text{.}\) Calcule \(\int_C \vec{F} \cdot d\vec{r}\text{,}\) onde \(C\) é uma curva qualquer \(C^1\) por partes ligando \(A = (\pi, 0)\) até \(B = (0, \pi)\text{.}\)
    Solução.
    Basta encontrar uma função potencial \(\varphi: \mathbb{R}^2 \rightarrow \mathbb{R}\) tal que \(\nabla\varphi = \vec{F}(x,y)\text{.}\) Queremos:
    \begin{align*} \frac{\partial\varphi}{\partial x} \amp = e^{-y} - 2x \quad \text{(1)}\\ \frac{\partial\varphi}{\partial y} \amp = -x e^{-y} - \text{sen } y \quad \text{(2)} \end{align*}
    Integrando a equação (1) em relação a \(x\text{:}\)
    \begin{equation*} \varphi(x,y) = \int (e^{-y} - 2x) \, dx = x e^{-y} - x^2 + g(y) \quad \text{(3)} \end{equation*}
    Derivando a equação (3) em relação a \(y\text{:}\)
    \begin{equation*} \frac{\partial\varphi}{\partial y}(x,y) = -x e^{-y} + g'(y) \quad \text{(4)} \end{equation*}
    Comparando (4) com a equação (2):
    \begin{equation*} -x e^{-y} + g'(y) = -x e^{-y} - \text{sen } y \implies g'(y) = -\text{sen } y \end{equation*}
    Integrando em relação a \(y\text{:}\) \(g(y) = \cos y + K\text{.}\)
    Daí, uma função potencial é \(\varphi(x,y) = x e^{-y} - x^2 + \cos y + K\text{.}\)
    Portanto:
    \begin{align*} \int_{C} \vec{F} \cdot d\vec{r} \amp = \varphi(0, \pi) - \varphi(\pi, 0)\\ \amp = \big(0 \cdot e^{-\pi} - 0^2 + \cos\pi + K\big) - \big(\pi e^{0} - \pi^2 + \cos 0 + K\big)\\ \amp = (-1) - (\pi - \pi^2 + 1) = \pi^2 - \pi - 2 \end{align*}
    Uma curva \(\gamma\) é dita fechada quando seus pontos extremos coincidem, ou seja, \(\gamma(a) = \gamma(b)\text{.}\)

    Teorema 2.3.6.

    A integral de linha \(\int_{\gamma} \vec{F} \cdot d\vec{r}\) é independente do caminho se, e somente se, \(\int_{\gamma} \vec{F} \cdot d\vec{r} = 0\) para toda curva \(\gamma\) fechada.

    Demonstração.

    (\(\implies\)) Seja \(\vec{F}: D \subseteq \mathbb{R}^n \rightarrow \mathbb{R}^n\) um campo vetorial tal que \(\int_C \vec{F} \cdot d\vec{r}\) seja independente do caminho para quaisquer curvas ligando os pontos \(A\) até \(B\text{.}\)
    Seja \(\gamma\) uma curva qualquer \(C^1\) fechada contendo os pontos \(A\) e \(B\text{.}\) Podemos ver \(\gamma\) composta por dois caminhos: \(\gamma_1\) de \(A\) para \(B\text{,}\) e \(\gamma_2\) de \(B\) para \(A\text{.}\) Assim:
    \begin{equation*} \int_{\gamma} \vec{F} \cdot d\vec{r} = \int_{\gamma_1} \vec{F} \cdot d\vec{r} + \int_{\gamma_2} \vec{F} \cdot d\vec{r} \end{equation*}
    Note que \(\int_{\gamma_2} \vec{F} \cdot d\vec{r} = -\int_{-\gamma_2} \vec{F} \cdot d\vec{r}\text{,}\) onde \(-\gamma_2\) é a curva percorrida no sentido contrário (de \(A\) para \(B\)). Logo:
    \begin{equation*} \int_{\gamma} \vec{F} \cdot d\vec{r} = \int_{\gamma_1} \vec{F} \cdot d\vec{r} - \int_{-\gamma_2} \vec{F} \cdot d\vec{r} = 0 \end{equation*}
    pois \(\gamma_1\) e \(-\gamma_2\) têm os mesmos pontos inicial e final e a integral é independente do caminho.
    (\(\impliedby\)) Agora, suponha que \(\int_{\gamma} \vec{F} \cdot d\vec{r} = 0\) para toda curva fechada \(\gamma\text{.}\) Sejam \(C_1\) e \(C_2\) duas curvas quaisquer ligando \(A\) até \(B\text{.}\)
    Note que a curva composta \(\gamma = C_1 \cup (-C_2)\) é fechada. Logo:
    \begin{align*} 0 = \int_{\gamma} \vec{F} \cdot d\vec{r} \amp = \int_{C_1} \vec{F} \cdot d\vec{r} + \int_{-C_2} \vec{F} \cdot d\vec{r}\\ 0 \amp = \int_{C_1} \vec{F} \cdot d\vec{r} - \int_{C_2} \vec{F} \cdot d\vec{r} \implies \int_{C_1} \vec{F} \cdot d\vec{r} = \int_{C_2} \vec{F} \cdot d\vec{r} \end{align*}

    Subseção 2.3.2 Critérios de Conservatividade em Domínios Abertos e Conexos

    Se o domínio do campo \(\vec{F}: \Omega \subset \mathbb{R}^n \rightarrow \mathbb{R}^n\) for "bem comportado", a independência do caminho implica que \(\vec{F}\) é conservativo.
    Aqui, "bem comportado" significa que \(\Omega\) é um conjunto:
    • Aberto: Todo ponto de \(\Omega\) pode ser colocado no centro de uma bola totalmente contida em \(\Omega\) (não contém pontos de fronteira).
    • Conexo por caminhos: Quaisquer dois pontos em \(\Omega\) podem ser ligados por um caminho totalmente contido em \(\Omega\text{.}\)

    Teorema 2.3.9.

    Se \(\vec{F}\) for um campo vetorial contínuo em uma região aberta e conexa por caminhos \(\Omega \subseteq \mathbb{R}^n\text{,}\) e se \(\int_C \vec{F} \cdot d\vec{r}\) for independente do caminho, então \(\vec{F}\) é conservativo em \(\Omega\text{.}\)

    Demonstração.

    Denote por \(\vec{e}_i = (0, \dots, 0, 1, 0, \dots, 0)\) o vetor da base canônica com \(1\) na \(i\)-ésima posição. Assim, \(\vec{F}(x_1, \dots, x_n) = \sum_{i=1}^{n} f_i(x_1, \dots, x_n)\vec{e}_i\text{.}\)
    Seja \(A \in \Omega\) fixado. Para cada ponto \(X = (x_1, \dots, x_n) \in \Omega\text{,}\) defina a função candidato a potencial:
    \begin{equation*} \varphi(X) = \int_{A}^{X} \vec{F} \cdot d\vec{r} \end{equation*}
    A notação \(\int_A^X\) é adequada pois a integral é independente do caminho escolhido ligando \(A\) a \(X\text{.}\)
    Vamos provar que \(\frac{\partial\varphi}{\partial x_i} = f_i\) para todo \(i = 1, \dots, n\text{.}\) Como \(\Omega\) é aberto, para \(X \in \Omega\) existe uma bola de centro \(X\) contida em \(\Omega\text{.}\) Considere \(h > 0\) suficientemente pequeno tal que o segmento ligando \(X\) a \(X + h\vec{e}_i\) esteja contido nessa bola.
    Note que:
    \begin{equation*} \frac{\varphi(X + h\vec{e}_i) - \varphi(X)}{h} = \frac{\int_{A}^{X+h\vec{e}_i} \vec{F}\cdot d\vec{r} - \int_{A}^{X} \vec{F}\cdot d\vec{r}}{h} = \frac{\int_{X}^{X+h\vec{e}_i} \vec{F}\cdot d\vec{r}}{h} \end{equation*}
    Uma parametrização do segmento de \(X\) a \(X + h\vec{e}_i\) é \(\gamma(t) = X + t\vec{e}_i\text{,}\) \(t \in [0, h]\text{.}\) Daí, \(\gamma'(t) = \vec{e}_i\text{,}\) e:
    \begin{equation*} \int_{X}^{X+h\vec{e}_i} \vec{F} \cdot d\vec{r} = \int_{0}^{h} \vec{F}(\gamma(t)) \cdot \vec{e}_i \, dt = \int_{0}^{h} f_i(\gamma(t)) \, dt \end{equation*}
    pois \(\vec{e}_i \cdot \vec{e}_i = 1\) e \(\vec{e}_j \cdot \vec{e}_i = 0\) para \(j \neq i\text{.}\)
    Aplicando o Teorema Fundamental do Cálculo (ou a Regra de L'Hôpital / Teorema do Valor Médio para Integrais):
    \begin{equation*} \lim_{h \to 0^+} \frac{\int_{0}^{h} f_i(\gamma(t)) \, dt}{h} = \lim_{h \to 0^+} f_i(\gamma(h)) = \lim_{h \to 0^+} f_i(X + h\vec{e}_i) = f_i(X) \end{equation*}
    Analogamente, considerando a parametrização \(\beta(t) = X - t\vec{e}_i\) para \(h \lt 0\text{,}\) obtém-se o limite à esquerda \(f_i(X)\text{.}\)
    Portanto:
    \begin{equation*} \frac{\partial\varphi}{\partial x_i}(X) = \lim_{h \to 0} \frac{\varphi(X + h\vec{e}_i) - \varphi(X)}{h} = f_i(X) \end{equation*}
    Mostrando que \(\nabla\varphi(X) = \vec{F}(X)\) para todo \(X \in \Omega\text{.}\)

    Teorema 2.3.10. Teorema de Equivalências.

    Seja \(\vec{F}: \Omega \subseteq \mathbb{R}^n \rightarrow \mathbb{R}^n\) um campo vetorial contínuo no aberto conexo por caminhos \(\Omega\text{.}\) São equivalentes as seguintes afirmações:
    1. \(\vec{F}\) é conservativo em \(\Omega\text{.}\)
    2. \(\int_{\gamma} \vec{F} \cdot d\vec{r} = 0\) para toda curva \(\gamma\) fechada, \(C^1\) por partes em \(\Omega\text{.}\)
    3. \(\int_{\gamma} \vec{F} \cdot d\vec{r}\) é independente do caminho de integração em \(\Omega\text{.}\)

    Subseção 2.3.3 Teste para Campos Conservativos em Regiões Simplesmente Conexas

    Se \(\vec{F}(x,y) = P(x,y)\vec{i} + Q(x,y)\vec{j}\) é conservativo, existe \(\varphi: \mathbb{R}^2 \rightarrow \mathbb{R}\) tal que \(\frac{\partial\varphi}{\partial x} = P\) e \(\frac{\partial\varphi}{\partial y} = Q\text{.}\)
    Supondo \(\vec{F}\) de classe \(C^1\text{,}\) segue pelo Teorema das Derivadas Cruzadas (Clairaut-Schwarz) que \(\varphi\) é de classe \(C^2\text{:}\)
    \begin{equation*} \frac{\partial^2\varphi}{\partial y \partial x} = \frac{\partial P}{\partial y} \quad \text{e} \quad \frac{\partial^2\varphi}{\partial x \partial y} = \frac{\partial Q}{\partial x} \end{equation*}
    Como \(\frac{\partial^2\varphi}{\partial y \partial x} = \frac{\partial^2\varphi}{\partial x \partial y}\text{,}\) concluímos que:
    \begin{equation*} \frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} \end{equation*}

    Nota 2.3.11.

    Teste Necessário: Se \(\vec{F} = P\vec{i} + Q\vec{j}\) é um campo de classe \(C^1\) e \(\vec{F}\) é conservativo, então obrigatoriamente \(\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}\text{.}\)
    Contrapositiva: Se \(\frac{\partial P}{\partial y} \neq \frac{\partial Q}{\partial x}\text{,}\) então o campo \(\vec{F}\) não é conservativo.

    Exemplo 2.3.12.

    Considere \(\vec{F}(x,y) = -y\vec{i} + x\vec{j}\text{.}\)
    Solução.
    Temos \(P(x,y) = -y\) e \(Q(x,y) = x\text{.}\)
    Calculando as derivadas parciais:
    \begin{equation*} \frac{\partial P}{\partial y} = -1 \quad \text{e} \quad \frac{\partial Q}{\partial x} = 1 \end{equation*}
    Como \(\frac{\partial P}{\partial y} \neq \frac{\partial Q}{\partial x}\text{,}\) logo \(\vec{F}\) não é conservativo.
    A recíproca vale? A condição \(\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}\) garante que \(\vec{F}\) é conservativo apenas em domínios sem "furos".

    Definição 2.3.13.

    Uma curva \(\gamma(t)\text{,}\) \(a \le t \le b\text{,}\) é dita fechada simples quando \(\gamma(a) = \gamma(b)\) e não existem auto-interseções no intervalo aberto \((a,b)\text{.}\)
    Uma região \(D \subseteq \mathbb{R}^2\) aberta e conexa por caminhos é dita simplesmente conexa quando toda curva fechada simples em \(D\) delimita uma região totalmente contida em \(D\text{.}\)

    Teorema 2.3.15.

    Seja \(\vec{F} = P\vec{i} + Q\vec{j}\) um campo vetorial em uma região aberta simplesmente conexa \(D\text{.}\) Suponha que \(P\) e \(Q\) tenham derivadas parciais de primeira ordem contínuas em todo \(D\) e que:
    \begin{equation*} \frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} \end{equation*}
    Então \(\vec{F}\) é conservativo em \(D\text{.}\)

    Exemplo 2.3.16.

    Considere \(\vec{F}(x,y) = (3 + 2xy)\vec{i} + (x^2 - 3y^2)\vec{j}\text{.}\)
    1. O campo \(\vec{F}\) é conservativo?
    2. Calcule \(\int_{\gamma} \vec{F} \cdot d\vec{r}\text{,}\) onde \(\gamma(t) = (e^t \text{sen } t, e^t \cos t)\text{,}\) \(0 \le t \le \pi\text{.}\)
    Solução.
    a) Verificação de conservatividade: O domínio de \(\vec{F}\) é todo o plano \(\mathbb{R}^2\text{,}\) que é aberto e simplesmente conexo. Sendo \(P(x,y) = 3 + 2xy\) e \(Q(x,y) = x^2 - 3y^2\text{,}\) temos:
    \begin{equation*} \frac{\partial P}{\partial y} = 2x \quad \text{e} \quad \frac{\partial Q}{\partial x} = 2x \end{equation*}
    Como \(\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}\) em \(\mathbb{R}^2\text{,}\) o teorema garante que \(\vec{F}\) é conservativo.
    b) Cálculo da integral de linha: Sendo conservativo, existe \(f(x,y)\) tal que \(\nabla f = \vec{F}\text{.}\)
    \begin{align*} \frac{\partial f}{\partial x} \amp = 3 + 2xy \quad \text{(1)}\\ \frac{\partial f}{\partial y} \amp = x^2 - 3y^2 \quad \text{(2)} \end{align*}
    Integrando (1) em relação a \(x\text{:}\) \(f(x,y) = 3x + x^2y + C(y)\text{.}\) Derivando em relação a \(y\text{:}\) \(\frac{\partial f}{\partial y} = x^2 + C'(y)\text{.}\) Comparando com (2): \(C'(y) = -3y^2 \implies C(y) = -y^3 + K\text{.}\) Logo, \(f(x,y) = 3x + x^2y - y^3 + K\text{.}\)
    Avaliando os pontos extremos da curva \(\gamma(t)\text{:}\)
    \begin{align*} \gamma(0) \amp = (e^0 \text{sen } 0, e^0 \cos 0) = (0, 1)\\ \gamma(\pi) \amp = (e^{\pi} \text{sen } \pi, e^{\pi} \cos \pi) = (0, -e^{\pi}) \end{align*}
    Pelo Teorema Fundamental:
    \begin{align*} \int_{\gamma} \vec{F} \cdot d\vec{r} \amp = f(\gamma(\pi)) - f(\gamma(0)) = f(0, -e^{\pi}) - f(0, 1)\\ \amp = \big(-(-e^{\pi})^3 + K\big) - (-1 + K) = e^{3\pi} + 1 \end{align*}

    Exemplo 2.3.17.

    Considere a curva \(C\) parametrizada por \(\alpha(t) = \left( e^{t-1}, \text{sen}\left(\frac{\pi}{t}\right) \right)\text{,}\) \(1 \le t \le 2\text{.}\) Calcule \(\int_C \vec{F} \cdot d\vec{r}\text{,}\) onde \(\vec{F}(x,y) = (2x\cos y, -x^2\text{sen } y)\text{.}\)
    Solução.
    Note que \(\vec{F}\) é de classe \(C^1\) em \(\Omega = \mathbb{R}^2\text{.}\) Além disso:
    \begin{equation*} \frac{\partial P}{\partial y} = \frac{\partial}{\partial y}(2x\cos y) = -2x\text{sen } y \quad \text{e} \quad \frac{\partial Q}{\partial x} = \frac{\partial}{\partial x}(-x^2\text{sen } y) = -2x\text{sen } y \end{equation*}
    Logo, \(\vec{F}\) é conservativo.
    Método 1: Por Função Potencial
    Integrando \(\frac{\partial\varphi}{\partial x} = 2x\cos y \implies \varphi(x,y) = x^2\cos y + g(y)\text{.}\) Derivando em \(y\text{:}\) \(\frac{\partial\varphi}{\partial y} = -x^2\text{sen } y + g'(y) = -x^2\text{sen } y \implies g'(y) = 0 \implies g(y) = K\text{.}\) Logo, \(\varphi(x,y) = x^2\cos y + K\text{.}\)
    Avaliando os pontos extremos: \(\alpha(1) = (1, 0)\) e \(\alpha(2) = (e, 1)\text{.}\)
    \begin{equation*} \int_{C} \vec{F} \cdot d\vec{r} = \varphi(e, 1) - \varphi(1, 0) = e^2 \cos 1 - 1 \end{equation*}
    Método 2: Por Troca de Caminho (Poligonal)
    Como \(\vec{F}\) é conservativo, a integral não depende do caminho entre \((1,0)\) e \((e,1)\text{.}\) Escolhemos a poligonal \(C_1 \cup C_2\) unindo \((1,0)\) a \((e,0)\) e \((e,0)\) a \((e,1)\text{:}\)
    • \(C_1(t) = (t, 0)\text{,}\) \(1 \le t \le e \implies C_1'(t) = (1, 0)\)
    • \(C_2(t) = (e, t)\text{,}\) \(0 \le t \le 1 \implies C_2'(t) = (0, 1)\)
    Calculando a integral sobre a poligonal:
    \begin{align*} \int_C \vec{F} \cdot d\vec{r} \amp = \int_{C_1} \vec{F} \cdot d\vec{r} + \int_{C_2} \vec{F} \cdot d\vec{r}\\ \amp = \int_{1}^{e} \vec{F}(t,0) \cdot (1,0) \, dt + \int_{0}^{1} \vec{F}(e,t) \cdot (0,1) \, dt\\ \amp = \int_{1}^{e} (2t\cos 0) \, dt + \int_{0}^{1} (-e^2\text{sen } t) \, dt\\ \amp = \int_{1}^{e} 2t \, dt - e^2 \int_{0}^{1} \text{sen } t \, dt\\ \amp = \left. t^2 \right|_{1}^{e} + \left. e^2 \cos t \right|_{0}^{1} = (e^2 - 1) + (e^2 \cos 1 - e^2) = e^2 \cos 1 - 1 \end{align*}

    Exercícios 2.3.4 Exercícios

    1.

    Determine uma função potencial \(f\) tal que \(\nabla f = \vec{F}\) e use isso para calcular a integral de linha sobre a curva \(C\) dada:
    1. \(\vec{F}(x,y) = \sqrt[3]{x}\vec{i} + \frac{1}{1+y^2}\vec{j}\text{,}\) onde \(\gamma\) é qualquer curva suave de \((0,0)\) a \((1,1)\text{.}\)
    2. \(\vec{F}(x,y,z) = (y^2z + 2xz^2)\vec{i} + 2xyz\vec{j} + (xy^2 + 2x^2z)\vec{k}\text{,}\) com \(C(t) = (\sqrt{t}, t+1, t^2)\text{,}\) \(0 \le t \le 1\text{.}\)
    3. \(\vec{F}(x,y,z) = \text{sen}(y)\vec{i} + (x\cos(y) + \cos(z))\vec{j} - (y\text{sen}(z))\vec{k}\text{,}\) com \(C: \vec{r}(t) = (\text{sen } t, t, 2t)\text{,}\) \(0 \le t \le \frac{\pi}{2}\text{.}\)

    2.

    Mostre que a integral de linha é independente do caminho e calcule seu valor:
    1. \(\int_{C} \tan(y) \, dx + x\sec^2(y) \, dy\text{,}\) de \((1,0)\) a \(\left(2, \frac{\pi}{4}\right)\text{.}\)
    2. \(\int_{C} (1 - y e^{-x}) \, dx + e^{-x} \, dy\text{,}\) de \((0,1)\) a \((1,2)\text{.}\)

    3.

    Seja \(f: \mathbb{R} \to \mathbb{R}\) contínua e considere o campo central \(\vec{F}(\vec{r}) = f(\|\vec{r}\|)\frac{\vec{r}}{\|\vec{r}\|}\text{.}\) Prove que \(\vec{F}\) é conservativo em \(\mathbb{R}^3 \setminus \{(0,0,0)\}\text{.}\)

    4.

    Mostre que se \(\vec{F} = P\vec{i} + Q\vec{j} + R\vec{k}\) é conservativo e \(C^1\text{,}\) então \(\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}\text{,}\) \(\frac{\partial P}{\partial z} = \frac{\partial R}{\partial x}\) e \(\frac{\partial Q}{\partial z} = \frac{\partial R}{\partial y}\text{.}\) Mostre ainda que a integral \(\int_{C} y \, dx + x \, dy + xyz \, dz\) não é independente do caminho.

    5.

    Seja o campo vetorial \(\vec{F}(x,y) = \frac{-y\vec{i} + x\vec{j}}{x^2 + y^2}\text{.}\)
    1. Mostre que \(\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}\) em todo o seu domínio \(\mathbb{R}^2 \setminus \{(0,0)\}\text{.}\)
    2. Calcule \(\int_{C_1}\vec{F}\cdot d\vec{r}\) e \(\int_{C_2}\vec{F}\cdot d\vec{r}\text{,}\) onde \(C_1\) e \(C_2\) são os semicírculos superior e inferior de \(x^2 + y^2 = 1\) de \((1,0)\) a \((-1,0)\text{.}\) Existe contradição com o item (a)?
