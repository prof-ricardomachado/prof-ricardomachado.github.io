Como o rotacional de \(\vec{F}\) é o vetor nulo (e o domínio do campo é todo o $\mathbb{R}^3$), o campo é conservativo. Pelo Teorema de Stokes, como \(C\) é uma curva fechada, a integral de linha de um campo irrotacional é zero:
\begin{equation*} \oint_C \vec{F} \cdot d\vec{r} = \iint_S \vec{0} \cdot d\vec{S} = 0 \end{equation*}
