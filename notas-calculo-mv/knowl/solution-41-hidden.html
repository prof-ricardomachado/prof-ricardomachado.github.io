Primeiro, verificamos se \(\text{rot}\,\vec{F} = \vec{0}\text{:}\)
\begin{gather*} \vec{i}\text{-comp: } \frac{\partial}{\partial y}(3xy^2z^2) - \frac{\partial}{\partial z}(2xyz^3) = 6xyz^2 - 6xyz^2 = 0\\ \vec{j}\text{-comp: } \frac{\partial}{\partial z}(y^2z^3) - \frac{\partial}{\partial x}(3xy^2z^2) = 3y^2z^2 - 3y^2z^2 = 0\\ \vec{k}\text{-comp: } \frac{\partial}{\partial x}(2xyz^3) - \frac{\partial}{\partial y}(y^2z^3) = 2yz^3 - 2yz^3 = 0 \end{gather*}
O campo é conservativo. Para encontrar \(f\text{,}\) igualamos \(\nabla f = \vec{F}\text{:}\)
\begin{equation*} \frac{\partial f}{\partial x} = y^2z^3 \implies f(x,y,z) = xy^2z^3 + g(y,z) \end{equation*}
Derivando em relação a \(y\text{:}\)
\begin{equation*} \frac{\partial f}{\partial y} = 2xyz^3 + \frac{\partial g}{\partial y} = 2xyz^3 \implies \frac{\partial g}{\partial y} = 0 \implies g(y,z) = h(z) \end{equation*}
Derivando em relação a \(z\text{:}\)
\begin{equation*} \frac{\partial f}{\partial z} = 3xy^2z^2 + h'(z) = 3xy^2z^2 \implies h'(z) = 0 \implies h(z) = C \end{equation*}
Logo, a função potencial é \(f(x,y,z) = xy^2z^3 + C\text{.}\)
