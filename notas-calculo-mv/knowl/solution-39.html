Solução 3.1.4.4.1.

Calculamos o rotacional de \(\vec{F}\text{:}\)
\begin{align*} \frac{\partial R}{\partial y} - \frac{\partial Q}{\partial z} \amp = \frac{\partial}{\partial y}(3xz^2) - \frac{\partial}{\partial z}(x^2) = 0 - 0 = 0\\ \frac{\partial P}{\partial z} - \frac{\partial R}{\partial x} \amp = \frac{\partial}{\partial z}(2xy + z^3) - \frac{\partial}{\partial x}(3xz^2) = 3z^2 - 3z^2 = 0\\ \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \amp = \frac{\partial}{\partial x}(x^2) - \frac{\partial}{\partial y}(2xy + z^3) = 2x - 2x = 0 \end{align*}
Como \(\text{rot}\,\vec{F} = 0\vec{i} + 0\vec{j} + 0\vec{k} = \vec{0}\) e o domínio é todo o \(\mathbb{R}^3\) (simplesmente conexo), o campo é conservativo.
