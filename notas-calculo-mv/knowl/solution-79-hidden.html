O divergente do campo simplifica-se para uma constante:
\begin{equation*} \text{div}\,\vec{F} = \frac{\partial}{\partial x}(x + \text{sen}\,y) + \frac{\partial}{\partial y}(y + \text{sen}\,z) + \frac{\partial}{\partial z}(z + \text{sen}\,x) = 1 + 1 + 1 = 3 \end{equation*}
Pelo Teorema do Divergente, \(\iint_S \vec{F} \cdot d\vec{S} = \iiint_E 3 \, dV\text{.}\) A interseção do paraboloide com o plano \(z = 0\) é a circunferência \(x^2 + y^2 = 4\text{.}\) Usando coordenadas cilíndricas (\(0 \le r \le 2\text{,}\) \(0 \le \theta \le 2\pi\text{,}\) \(0 \le z \le 4 - r^2\)):
\begin{align*} \iint_S \vec{F} \cdot d\vec{S} \amp = 3 \int_0^{2\pi} \int_0^2 \int_0^{4-r^2} r \, dz \, dr \, d\theta = 6\pi \int_0^2 r(4 - r^2) \, dr\\ \amp = 6\pi \left[ 2r^2 - \frac{r^4}{4} \right]_0^2 = 6\pi (8 - 4) = 24\pi \end{align*}
