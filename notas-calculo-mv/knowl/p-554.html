Considere o sólido \(B = \{(x,y,z) \in \mathbb{R}^3 : x \ge 0, y \ge 0, 0 \le z \le 1 - x - y\}\) com fronteira orientada para fora \(\sigma\text{,}\) e o campo \(\vec{F}(x,y,z) = x\vec{i} + y\vec{j} + z\vec{k}\text{.}\) Verifique que:
\begin{equation*} \iint_{\sigma} \vec{F} \cdot \vec{n} \, dS = \iiint_{B} \text{div}\,\vec{F} \, dV \end{equation*}
