Item a) Potencial: \(f(x,y) = \frac{3}{4}x^{4/3} + \arctan(y)\text{.}\)
\begin{equation*} \int_\gamma \vec{F}\cdot d\vec{r} = f(1,1) - f(0,0) = \frac{3}{4} + \frac{\pi}{4} = \frac{3+\pi}{4} \end{equation*}
Item b) Potencial: \(f(x,y,z) = xy^2z + x^2z^2\text{.}\) Extremos: \(C(0) = (0,1,0)\) e \(C(1) = (1,2,1)\text{.}\)
\begin{equation*} \int_C \vec{F}\cdot d\vec{r} = f(1,2,1) - f(0,1,0) = (4 + 1) - 0 = 5 \end{equation*}
Item c) Potencial: \(f(x,y,z) = x\text{sen } y + y\cos z\text{.}\) Extremos: \(\vec{r}(0) = (0,0,0)\) e \(\vec{r}(\pi/2) = (1, \pi/2, \pi)\text{.}\)
\begin{equation*} \int_C \vec{F}\cdot d\vec{r} = f(1, \pi/2, \pi) - f(0,0,0) = 1 - \frac{\pi}{2} \end{equation*}
